# Convolutional Neural Networks (CNN)

This directory contains my notes on **Convolutional Neural Networks (CNNs)** from my Deep Learning learning journey during the **Ebryx Machine Learning Internship**.

CNNs are specialized neural networks designed for processing image and spatial data. These notes cover the core building blocks of CNNs, how they learn visual features, techniques to improve training, and an introduction to influential CNN architectures.

---

## Topics Covered

| Topic | Description |
|-------|-------------|
| **Introduction to CNNs** | Overview of CNNs, motivation, advantages over ANNs, and basic architecture. |
| **Convolution, Filters & Feature Maps** | Understanding convolution operations, kernels (filters), feature extraction, and feature maps. |
| **Padding, Stride & Pooling** | Learn how padding preserves image dimensions, stride controls filter movement, and pooling reduces feature map size. |
| **Dropout & Batch Normalization** | Regularization and normalization techniques used to improve generalization and stabilize training. |
| **CNN Architectures (Intro)** | Introduction to LeNet, VGG, and ResNet, their architectures, strengths, and historical significance. |

---

## Learning Objectives

After completing these notes, you should be able to:

- Explain why CNNs outperform traditional ANNs on image data.
- Understand how convolution extracts meaningful visual features.
- Describe the purpose of filters, kernels, and feature maps.
- Calculate output dimensions after convolution using stride and padding.
- Explain the role of max pooling and average pooling.
- Understand how Dropout helps reduce overfitting.
- Explain how Batch Normalization improves training stability.
- Compare the architectures and applications of LeNet, VGG, and ResNet.
- Build and understand basic CNN models using TensorFlow/Keras.
