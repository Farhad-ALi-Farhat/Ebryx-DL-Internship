# Deep Learning Notes

This directory contains my personal notes and practical implementations from my **Ebryx Machine Learning Internship** focused on **Deep Learning**.

The notes cover the fundamental concepts of neural networks, deep learning workflows, training techniques, and model optimization. Each topic includes concise explanations, mathematical formulas, and practical insights to build a strong foundation before moving on to advanced architectures such as CNNs, RNNs, and Transformers.

## Topics Covered

- Introduction to Deep Learning and Neural Networks
- Artificial Neurons, Weights, Bias, and Activation Functions
- Loss Functions (Mean Squared Error, Cross-Entropy)
- Optimizers (SGD, Adam)
- Forward and Backward Propagation
- Overfitting, Underfitting, and Regularization

## Learning Objectives

By completing these notes, you will understand:

- The fundamentals of deep learning and artificial neural networks.
- How neurons process information using weights, biases, and activation functions.
- The purpose and selection of different loss functions.
- How optimizers update model parameters during training.
- The concepts of forward propagation and backpropagation.
- Common challenges such as overfitting and underfitting, along with techniques to improve model generalization.

---

These notes serve as a foundation for more advanced deep learning topics, including **Convolutional Neural Networks (CNNs)**, **Recurrent Neural Networks (RNNs)**, **Transformers**, **Transfer Learning**, and other modern deep learning architectures.
